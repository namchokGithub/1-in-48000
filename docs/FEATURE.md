# สรุป Feature

ภาพรวม feature ของ "1 ใน 48,000" แยกเป็นฝั่ง Player (เกมที่เผยแพร่) และ BO (เครื่องมือเขียนเนื้อเรื่องที่รันบนเครื่องผู้เขียนเท่านั้น) กติกาละเอียดอยู่ที่ [`GAME-RULES.md`](GAME-RULES.md) และวิธีเขียนเนื้อเรื่องอยู่ที่ [`STORY-AUTHORING.md`](STORY-AUTHORING.md)

## Player

### เริ่มพื้นฐานตัวละครได้หลายแบบ

- เกมสุ่มชื่อผู้เล่นและรูปตัวละครให้จาก seed ของรอบนั้น
- เลือกพื้นหลังได้ 1 ใน 3 แบบ หรือกดสุ่ม ตัวเลือกแรกเป็น "เริ่มต้นชีวิตในแบบของเรา" เสมอ อีก 2 แบบสุ่มจากพื้นหลังทั้งหมด 10 แบบ
- พื้นหลังแต่ละแบบบอกฐานะครอบครัว นิสัย และทักษะ และเปลี่ยนค่าสถานะเริ่มต้น เช่น

| พื้นหลัง                                | จุดเด่น                       |
| --------------------------------------- | ----------------------------- |
| `balanced` เริ่มต้นชีวิตในแบบของเรา     | ค่ากลางทุกอย่าง               |
| `supported` มีบ้านคอยซัพพอร์ต           | เงิน +3,000 สุขภาพ −10        |
| `outgoing` ชีวิตมหาลัย เพื่อนต้องมาก่อน | ความสัมพันธ์ +50 การเรียน −10 |
| `hardworking` ชีวิตนี้ต้องสร้างเอง      | การเรียน +20 ความเครียด +10   |
| `academic` เรื่องเรียนไว้ก่อน           | การเรียน +15 ความเครียด +30   |
| `extremely_lucky` เกิดมาดวงดีเกินต้าน   | โชค +88                       |
| `extremely_unlucky` ชีวิตนี้ดวงซวยจัด   | โชค −88 เงิน −500             |

- เลือกคณะและสาขาจาก 24 คณะ 49 สาขา บางสาขาเป็นหลักสูตร 6 ปี (แพทย์ เภสัช ทันตะ เดินเรือ) และมีเนื้อเรื่องปี 5–6 แยกของตัวเอง

### ปิดเปิดสถานะได้ ลุ้นไปด้วยกัน

- ใต้แต่ละ choice จะแสดงว่าค่าสถานะใดเพิ่มหรือลดเท่าไร
- ผู้เล่นปิดการแสดงผลนี้ได้จากปุ่มบนหัวจอ เกมจำค่านี้ไว้ในเบราว์เซอร์
- ผู้เขียนซ่อนได้ทีละ event (`hideStatChanges`) เพื่อให้ลุ้นผลเอง
- choice จะแสดงตัวเลขก็ต่อเมื่อทั้งผู้เล่นและ event อนุญาต
- ค่าที่ถูกซ่อนยังแสดงย้อนหลังในสรุปรายปีและไทม์ไลน์ตอนจบ

### เวลาและการจบการศึกษา

- แต่ละปีมี 4 ช่วง: เทอม 1 → ปิดเทอม → เทอม 2 → ซัมเมอร์
- มีการตรวจผลการเรียนที่ปี 4, 6 และ 8 หลักสูตร 4 ปีตรวจครั้งแรกที่ปี 4 ส่วนหลักสูตร 6 ปีตรวจครั้งแรกที่ปี 6
- ถ้าไม่ผ่านจะเรียนต่อได้จนถึงปี 8 ปีที่เกินหลักสูตร (ปี 5–8) มีเนื้อเรื่องของตัวเอง
- ขึ้นปีใหม่ เกมจะสรุปปีที่แล้วให้ดู ได้แก่ค่าสถานะที่เปลี่ยน เงินเข้าออก และ event ที่ผ่านมา

### ค่าสถานะ

| ค่า             | ความหมาย     | ขอบเขต                           |
| --------------- | ------------ | -------------------------------- |
| `study`         | การเรียน     | สูงสุด 100 ติดลบได้              |
| `health`        | สุขภาพ       | สูงสุด 100 ติดลบได้              |
| `stress`        | ความเครียด   | สูงสุด 100 ติดลบได้              |
| `relationships` | ความสัมพันธ์ | สูงสุด 100 ติดลบได้              |
| `lucky`         | โชค          | สูงสุด 100 ติดลบได้              |
| `money`         | เงิน (บาท)   | ไม่มีขอบเขต ติดลบ = กู้อัตโนมัติ |
| `debt`          | หนี้         | ต่ำสุด 0                         |

- **กู้อัตโนมัติ:** เงินติดลบได้ ยอดที่ติดลบคิดดอกเบี้ยรายปีทุกครั้งที่จบช่วงเวลา ตอนนี้อัตรา 22%
- **หนี้:** ตอนจบเกม หนี้จะถูกหักจากเงิน หน้าจอจบแสดงการหักนี้ให้ดู

### กฎชีวิต (ตั้งค่าได้ใน BO)

- **เปลี่ยนทุกช่วงเวลา:** ค่าสถานะเปลี่ยนเองทุกครั้งที่จบช่วงเวลา และใส่เงื่อนไขได้ เช่น การเรียนลดลงช่วงปิดเทอม ค่าใช้จ่ายรายช่วง หรือสุขภาพลดเมื่อเครียดเกิน 40
- **ตัวคูณ:** ค่าหนึ่งทำให้อีกค่าเพิ่มหรือลดเร็วขึ้นหรือช้าลง เช่น สุขภาพต่ำกว่า 50 ทำให้การเรียนเพิ่มได้น้อยลง 20% หรือโชคเกิน 60 ทำให้เงินเปลี่ยนมากขึ้น 30%
- **จบเกมกลางทาง:** ถ้าค่าใดเกินเกณฑ์ เกมจบทันที ได้แก่ การเรียนต่ำกว่า 20 = พ้นสภาพ, สุขภาพต่ำกว่า 15 = ร่างกายไม่ไหว, ความเครียดเกิน 70 = ชีวิตที่แบกรับมากเกินไป

### Event และ choice

- มี 319 event แบ่งเป็นเรื่องหลัก เรื่องตามเงื่อนไข วันหยุดไทย และ random event (เช่น ศาลเจ้า ตลาดเดินได้ เที่ยวกลางคืน ล่าผี ป่วย)
- **ผลของ choice:** มีผลทันที มีผลภายหลัง (ทั้งดีและร้าย) หรือแค่เปลี่ยนบทพูด
- **choice ที่ยังเลือกไม่ได้:** แสดงเหตุผลที่ล็อกไว้ เช่น "ต้องมีเงินอย่างน้อย 500 ฿"
- **บางสาขามี** event เลือกได้หลายข้อ และวิชาเลือก
- **ทวนผล:** choice ทิ้งข้อความสั้นๆ ไว้ทวนใน event ถัดไปได้
- **ความจำของเกม:** เกมจำการตัดสินใจไว้ เช่น เคยช่วยเพื่อน เข้าชมรม หรือทำงานพิเศษ และนำมาใช้ภายหลัง แต่ผลไม่ได้ดีเสมอไป

### ฉากจบ

- มี 6 แบบ: เส้นทางนักค้นคว้า (`academic_path`), เส้นทางที่เดินกับผู้คน (`community_path`), จบการศึกษา (`graduation`), พ้นสภาพ (`dismissal`), ร่างกายไม่ไหว (`burnout`), ชีวิตที่แบกรับมากเกินไป (`overwhelmed_by_stress`)
- หน้าจอจบแสดงเกรดเฉลี่ยจากค่าการเรียน:
  - การเรียน 100 = 4.00
  - 80, 60, 40 และ 0 เป็นจุดเริ่มของช่วง 3, 2, 1 และ 0 ทศนิยมสุ่มจาก seed ของรอบนั้น
  - การเรียนติดลบ = 0.00
- หน้าจอจบมีไทม์ไลน์ชีวิตด้วย

### อื่น ๆ

- **ภาพและเสียง:** ฉาก pixel art 40 ภาพ, รูปตัวละคร 25 รูป, เพลงพื้นหลังวนเล่นพร้อมปุ่มเปิดปิด
- **เซฟ:** บันทึกเมื่อเลือก choice กด refresh ในแท็บเดิมจะเล่นต่อได้ ถ้าเปิดใหม่หรือกดกลับหน้าแรกจะเริ่มใหม่
- **อุปกรณ์:** ใช้ได้ทั้งมือถือและเดสก์ท็อป และมีธีมสว่าง/มืด
- **แจ้งปัญหา / เสนอเรื่องราว:**
  - footer หน้าแรกมีลิงก์ไป GitHub (ต้องมีบัญชี GitHub)
  - แจ้งบั๊กและคำผิดผ่าน Issues ด้วยฟอร์มภาษาไทย
  - เสนอเรื่องราวใน Discussions หมวด Story Suggestions

## BO (Back Office)

เปิดที่ `/content-manage` ตอนรัน `pnpm dev` และไม่อยู่ใน production build

### เนื้อเรื่อง

- **Event:** เพิ่ม แก้ และลบ event, choice และฉากจบ สร้าง id แบบ `snake_case` ได้ในตัวแก้ไข
- **ค้นหา:** ใช้ได้กับ id, ชื่อ event, บทพูด และข้อความ choice
- **Asset:** ผูกภาพฉาก ผู้พูด เพลง และเสียงด้วย Asset ID
- **Flag:** รายการ flag ทั้งหมด บอกว่าแต่ละตัวถูกตั้งและถูกเช็คที่ไหน

### Story Flow

- **การ์ด:** วาง event แล้วต่อ choice ไปการ์ดถัดไป มีการ์ด Condition, Random, Next Period และ Ending
- **Sub Flow:** จัดกลุ่มการ์ดเป็น Sub Flow มีเมนูกระโดดไป Sub Flow และล็อก/ปลดล็อกทีละกลุ่ม เพื่อไม่ให้เผลอลากทั้งกลุ่ม
- **จัดตำแหน่ง:** มีเส้นช่วยจัดแนว (helper lines) และไกด์ระยะห่างเท่ากัน การ์ดดูดเข้ากริดตอนปล่อยเมาส์
- **นำทาง:** ช่อง "ไปที่การ์ด..." พร้อม badge นับ event/condition, ตัวกรอง event, โฟกัสเส้นทางใกล้เคียง และ Undo/Redo
- **ทดลองเล่น:** Simulation เปิดจากการ์ดได้ด้วยคีย์ลัด มีหน้าต่าง Preview ที่เล่นเหมือน Player โดยไม่เขียนเซฟ บอกเส้นทางที่ผ่านพร้อมเหตุผลผ่าน/ไม่ผ่าน และไฮไลต์บนกระดาน

### ตรวจและบันทึก

- **ตรวจ:** id ซ้ำ ลิงก์ event เสีย Asset หาย choice ที่ไม่ได้ต่อ การ์ดที่ไปไม่ถึง และทางตัน
- **บันทึก:** เขียน JSON ลง `public/content-v2` โดยตรง ไม่มี import/export

### ตั้งค่าเกม

- อัตราดอกเบี้ยกู้และจำนวนวันต่อช่วง
- ตัวคูณ, จบเกมกลางทาง และเปลี่ยนทุกช่วงเวลา (ลากเพื่อเรียงลำดับกฎได้)

## Balance reports

`pnpm balance` จำลองการเล่นด้วยเนื้อหาจริงและ engine เดียวกับเกมหลายร้อยรอบ แล้วเขียนรายงานไว้ที่ `reports/balance/<เวลา>/summary.md` โฟลเดอร์นี้ไม่ถูก commit รายละเอียดอยู่ที่ [`BALANCE.md`](BALANCE.md)

```bash
pnpm balance --runs 500 --seed 100              # 500 รอบต่อ policy ผลซ้ำได้ด้วย seed เดิม
pnpm balance --runs 500 --policy random,study   # เลือกเฉพาะบาง policy
```

**Policy** คือรูปแบบการเลือก choice ของผู้เล่นจำลอง:

- `random`: สุ่ม
- `study`: เน้นเรียน
- `money`: เน้นเงิน
- `health`: เน้นสุขภาพ
- `social`: เน้นเพื่อน
- `chill`: เน้นพักผ่อน

**รายงานมีตาราง:**

- ฉากจบแยกตาม policy และหลักสูตร (4/6 ปี)
- ค่าสถานะตอนจบ: ค่ากลาง, p10–p90, เกรด และยอดกู้ค้าง
- Watch list: ค่าที่ชนเพดานหรือติดลบ
- choice ที่ขยับค่าตอนจบมากที่สุด
- choice ที่เปลี่ยนค่ามากที่สุดในเนื้อหา
- event ที่ไม่มีใครไปถึงหรือไปถึงน้อย

**อ่านผลได้ว่า**

- random เล่นจบรวมราว 58% ใกล้เป้า สาเหตุหลักที่ไม่จบคือพ้นสภาพ

- ทุก event ถูกเล่นถึง (319/319) ส่วนที่ไปถึงน้อยคือฉากคณะในหลักสูตร 6 ปีและปีที่เกินหลักสูตร
- ข้อที่ยังเฝ้าดูอยู่: ความสัมพันธ์แตะ 100 ใน 26–57% ของรอบ และโชคแทบไม่เปลี่ยนนอกจากที่ได้จากพื้นหลัง
