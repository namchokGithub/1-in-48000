# บริบทภาพตัวละครและฉาก

เอกสารนี้อธิบายภาพที่สร้างไว้ใน `public/assets/template/` เพื่อใช้เป็นแนวทางเมื่อเลือกภาพไปประกอบเกมหรือสร้างภาพเพิ่มเติม ภาพชุดนี้เป็น **ไฟล์ต้นแบบ**; เกมยังไม่ได้เปลี่ยนมาใช้ภาพเหล่านี้โดยอัตโนมัติ

## แนวทางภาพร่วมกัน

- ภาพทั้งหมดเป็น PNG พิกเซลอาร์ตแนวเกมเรโทร 8 บิต ใช้รูปทรงและขอบพิกเซลที่คมชัด
- สไปรต์ตัวละครมีขนาด **96×171 px** พื้นหลังโปร่งใส มองตรงและเห็นเต็มตัว
- ภาพฉากมีขนาด **320×180 px** เป็นพื้นหลังทึบ เว้นพื้นที่ให้วางตัวละครและบทสนทนา
- สีหลักของฉากเป็นฟ้าสด เขียวของต้นไม้ ครีมอุ่น และกรมท่า ให้เข้ากับฉากหน้ามหาวิทยาลัยและสไปรต์
- เมื่อแสดงภาพหรือปรับขนาดในอนาคต ให้ใช้ nearest-neighbor เพื่อรักษาขอบพิกเซล ไม่ทำให้ภาพนุ่มหรือเบลอ
- ใช้ชื่อสถาบันสมมติ **มหาวิทยาลัยบารพู** เท่านั้น

## การนำไปใช้ในเกม

ไฟล์ใน `public/assets/template/` ยังเป็นชุดภาพสำหรับพิจารณา ไม่ใช่เส้นทางที่ `public/content-v2/assets.json` อ้างอยู่ในปัจจุบัน ฉากที่เกมใช้อยู่ยังชี้ไปที่ `public/assets/scene/` หากจะนำภาพต้นแบบไปใช้จริง ให้คัดลอกไปยังตำแหน่ง asset ที่ต้องการ แล้วแก้รายการใน asset manifest ให้เกมอ้างผ่าน **Asset ID** ตามกฎของโครงการ
